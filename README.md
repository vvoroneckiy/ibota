Ироничный чат-бот для ВКонтакте, написанный на Python с использованием фреймворка vkbottle. 

  Особенности
* База на 100 фраз: Все тексты изолированы в файле phrases.py.
* Слежка за режимом: Бот динамически подстраивает приветствия под время суток (стебёт полуночников).
* Безопасность (.env): Секретный токен группы надёжно спрятан от чужих глаз.
* Windows-совместимость: Вшит автоматический обход капризов с SSL-сертификатами.

  Быстрый старт
1. Установите библиотеки:
   pip install vkbottle aiohttp python-dotenv
2. Создайте файл .env в корне проекта и укажите ваш токен:
   TOKEN=ваш_токен_сообщества_здесь
3. Запустите проект:
   python bot.py
